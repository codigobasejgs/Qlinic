# Aplicação da identidade Qlinic

Use este pacote como fonte visual do projeto. Preserve todos os SVGs e proporções.
Importe os tokens CSS e JSON; mapeie-os para a stack atual sem duplicar paletas.
Use principal no light e reverso no dark. Sidebar deve ser sóbria e ações contrastantes.
Ative temas por data-theme. O seletor de marca do tenant deve gerar tokens acessíveis.
Qlinic é a identidade do Super Admin e site comercial. Para portais contratantes,
aplique a identidade cadastrada por eles e mantenha os padrões de interação.
Não converta a interface em uma coleção de cards com efeitos. Priorize agenda,
informação legível, ações contextuais e fluxo contínuo. Não modificar regras de negócio.
Instale os ícones PWA em URLs públicas persistentes e configure manifesto por tenant.
O manifesto incluído é apenas exemplo da marca-mãe, não solução multi-tenant pronta.
Verifique visualmente em 360, 390, 768, 1024 e 1440 px, ambos os temas, teclado e zoom.
